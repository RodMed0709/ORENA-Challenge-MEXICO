<objective>
Convert the frozen split's training videos into an ms-swift multimodal LoRA dataset (TRAIN-01 export half) with balanced sampling across `(capability group x answer_format)` cells (TRAIN-03). For each training QA row: pick 1-3 frames with the SHARED Phase-2 `sample_frames_from_paths` + pinned `POLICY`, save those exact frames to a cache, and emit one JSONL line `{"messages":[system,user,assistant], "images":[paths]}` with one `<image>` tag per image. Balance is applied at export time as a deterministic, capped, committed artifact (`balance_stats.csv`) — never as an opaque trainer knob.

Purpose: If the export samples/resizes frames differently from the engine, the model trains on a distribution it never sees at inference and OOD silently collapses — so the export MUST reuse Phase-2's `POLICY` + sampler + `SYSTEM_PROMPT` for train==serve parity (PITFALLS #3; ARCHITECTURE). Balancing at export (leveling counting/number and rare groups, capped <=4x) lifts weak buckets without drowning the model in near-duplicates, and being a pure function of the histogram it is identical on all 3 machines (TRAIN-03; PITFALLS #4).
Output: `src/frame/training/{balance,export}.py`, `scripts/export_jsonl.py`, and CPU tests.
</objective>

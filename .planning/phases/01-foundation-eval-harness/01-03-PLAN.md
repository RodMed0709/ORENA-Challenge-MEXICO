<objective>
Build the trustworthy local scorer — a THIN wrapper over `focus.Evaluator` that scores a precomputed `responses.json` with no model loaded, reproduces the SDK's `pre_evaluation_score` EXACTLY, hard-codes `Track.FRAME` (5.0s gate), and makes the LLM judge swappable (`no-judge` / `mock` / `real`) so the judge-routing branch is testable GPU-free. This plan also lays the Wave-0 test scaffold (`conftest.py`, `MockJudge`, stub responses) that Plan 01-04 extends.

Purpose: Phase 1's entire value is FIDELITY, not features. Every line of scoring we write is a line that can silently drift from the organizers' leaderboard number, so we EXTRACT from the SDK's `summary_df`/`buckets_df` and NEVER recompute a mean (RESEARCH Don't-Hand-Roll, Anti-Patterns). The `responses.json` seam decouples the harness author from the engine author (Phase 2 runs concurrently).
Output: `src/frame/eval/{judges,harness}.py`, `scripts/evaluate.py`, test scaffold + golden/EVAL tests.
</objective>

<!-- Exact SDK contracts (v0.3.4, read from source). Use directly — do NOT re-explore. -->

focus.Evaluator(judges: list[Judge] | None = None, adversarial_detector=None, lazy_judge=True,
                judge_kwargs=None, num_workers=1, n_boot=1000, seed=42)
  - judges=[]  => NO model loaded; every JUDGE_FORMATS question forced INCORRECT (majority_vote([])->False).
  - judges=None (default, lazy) => instantiates TransformersJudge("Qwen/Qwen3.5-4B") on first judge-format Q.
  - judges=[MockJudge(...)] => deterministic, GPU-free judge path.

Evaluator.run(requests, references, responses, output_dir=None, max_latency=None, track=None)
  -> (results_df, summary_df)
  - Pass track=Track.FRAME to enforce TRACK_MAX_LATENCY[FRAME]=5.0 (slower => timed_out + incorrect).
  - Passing BOTH max_latency and track raises ValueError.
  - DUPLICATE qID in responses => raises ValueError (aborts whole run) — do NOT suppress. (tested in 01-04)
  - AdversarialDetector.check runs on EVERY response.content and raises RuntimeError on flagged phrases
    → keep all stub/fixture response contents clean (no "correct"/"act as if"/"you are now"/etc.).
  - results_df columns: qID, video, ood, clinical, primary, answer_format, latency, timed_out, correctness.
  - summary_df: rows level in {leaf, group, answer_format, overall, latency?, pre_evaluation};
    the row level=="pre_evaluation", name=="SCORE" holds `accuracy`==pre_evaluation_score, `count`==#buckets.

Evaluator.pre_evaluation_score(results_df) -> (score: float, buckets_df)
  - score = unweighted mean over populated group×{ID,OOD} buckets; EXACT (pure means, no tolerance).
  - buckets_df columns: group, ood, accuracy, count.

focus.evaluation.judges.Judge  (ABC): single method  judge(request, reference: str, candidate: str) -> bool
focus.load_responses(path) -> list[Response]     ;  Response(qID:str, content:str, latency:float=0.0)
Exact-match formats (deterministic, no judge): number(str.isdigit->int), binary(yes/no->bool),
  fo_class(Title-Case set-equality), percentage(float isclose), time(hh:mm:ss tuple ~5s tol).
JUDGE_FORMATS = {open_ended, matching, multiple_choice}; `matching` is regex-gated BEFORE the judge.

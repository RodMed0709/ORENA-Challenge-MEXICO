<!-- Exact SDK contracts (v0.3.4, read from source). Use directly — do NOT re-explore. -->

focus.FocusDataset(dataset: str, split=DatasetSplit.TEST, track=None, revision=None, config=None)
  - Raises ValueError if `dataset not in {"heico","lapchole"}` (FOCUS_DATASETS keys).
  - track=Track.FRAME -> HF config_name "frame"; DatasetSplit.ALL -> HF split "train+test".
  - Annotations stream from HF via datasets.load_dataset; NO root_dir / NO videos / NO GPU needed.
  - Properties: .requests -> list[Request], .references -> list[Reference], .video_ids() -> set[str], len(ds).

focus.Request: qID:str, videoID:str, start_time:float, end_time:float, procedure_type:str, question:str
focus.Reference: qID:str, primary:Capability, _format:str, answer:str, format_kwargs:dict,
                 secondaries:tuple, ood:bool=False, clinical:bool
  - ref.format -> instantiated AnswerFormat (ref.format.read(text) parses; may raise ValueError).

focus.Capability (str Enum): .value (e.g. "object_identification"), .group -> parent Capability,
  .group.value (e.g. "object_recognition"), Capability.groups() -> 5 groups, Capability.leaves() -> 15.

Answer formats (ref._format literals, 8): binary, number, percentage, fo_class, open_ended,
  matching, multiple_choice, time.   NOTE it is `fo_class` (NOT `foclass`).
  Canonical parsed shapes via ref.format.read(answer):
    binary->bool, number->int, percentage->float, fo_class->frozenset[str],
    open_ended/matching/multiple_choice->str, time->tuple[timedelta,...].
  `matching` needs a `pattern` in format_kwargs; if a sampled matching answer lacks it, catch and
  record "requires pattern" rather than crashing the EDA.
</interfaces>

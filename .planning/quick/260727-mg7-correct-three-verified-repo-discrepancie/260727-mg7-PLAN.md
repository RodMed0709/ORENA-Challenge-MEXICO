**Root cause of our error:** the ABSTRACT says multi-task "reduces the Count MAE" — but that is
fine-tuned-vs-**public** *inside* the multi-task task (6.70 → 1.52), not a comparison across tasks.

**Caveat that MUST be preserved — do not overstate.** The rows are **different evaluation subsets**
(n = 105 / 91 / 98 / 99), so this is **not a strictly paired ablation**. It is nevertheless the only
evidence available and it points AGAINST adding pointing supervision for counting.

- lapchole minimum 640x360 = 230,400 px = 0.25x the cap → does NOT bind

i.e. **the cap never downscales any frame; every frame reaches the ViT at native resolution.**

# Challenge reference texts

Plain-text extractions of the official ORENA SAVE FOCUS challenge PDFs, kept here as
searchable source-of-truth for scope/rules (moved out of the repo root, 2026-07-14).

- `challenge_design.txt` — full challenge design (all three tracks: FRAME / SEGMENT / PROCEDURE, RQ1/RQ2, data, eval).
- `frame_track.txt` — FRAME-track spec (single-image VQA: FO identification, counting, attributes, spatial).

> Verbatim PDF text, only whitespace/page-header noise trimmed. `frame_track.txt` carries
> OCR artifacts from the source PDF (`=on`→`tion`, `�` for special glyphs) — left as-is,
> not hand-corrected, to avoid silent edits. Use `challenge_design.txt` when wording matters.
